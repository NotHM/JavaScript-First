# Unit 20: Final Capstone — Local Multimodal AI, Voice, Vision & 3D CAD/Print Pipeline

Unit 20 integrates the entire JavaScript engineering stack into a privacy-first **Full-Stack Local Multimodal AI Chat Application**, progressing from local LLM token streaming and cosine-similarity RAG to offline speech (STT/TTS), optional multimodal vision/video (**Bonus**), and parametric 3D CAD `.stl`/`.obj` generation for physical 3D printing (**Double Bonus — 2x Score**).
