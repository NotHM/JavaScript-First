# Unit 10 Guide: UCD, Accessibility, Responsive CSS, 2D Canvas & DOM

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 14–15 (Days 68–74 | 7 Class Periods × 50 Minutes)

## 1. Unit Overview
Unit 10 delivers comprehensive mastery of **AZ CTE Standard 15.0 (`15.1–15.11`)**. Students progress from **User-Centered Design (UCD)**, wireframes, **W3C Semantic HTML5**, **ADA Section 504/508 & WCAG Accessibility**, and **SEO (`15.1–15.3, 15.8–15.10`)** into **CSS Box Model / Flexbox / Grid / `@media`/`@print`**, **2D HTML5 Canvas Transforms** (`translate`/`rotate`/`scale`), GUI form validation, DOM events, and **UI/CSS Library evaluation (`15.4–15.7, 15.11`)**.
