# Unit 10 Guide: UCD, Accessibility, Responsive CSS, 2D Canvas & DOM

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 14–15 (Days 68–74 | 7 Class Periods × 50 Minutes)

## 1. Unit Overview
Unit 10 delivers comprehensive mastery of **AZ CTE Standard 15.0 (`15.1–15.11`)**. Students progress from **User-Centered Design (UCD)**, wireframes, **W3C Semantic HTML5**, **ADA Section 504/508 & WCAG Accessibility**, and **SEO (`15.1–15.3, 15.8–15.10`)** into **CSS Box Model / Flexbox / Grid / `@media`/`@print`**, **2D HTML5 Canvas Transforms** (`translate`/`rotate`/`scale`), GUI form validation, DOM events, and **UI/CSS Library evaluation (`15.4–15.7, 15.11`)**.

## 3. Bloom's Taxonomy Progression Matrix (L1 → L6)
| Tier | Focus | Evidence |
|---|---|---|
| **L1 Remember** | State WCAG contrast minimums (`4.5:1`), semantic HTML5 landmarks, Box Model layers, & Canvas transform methods | `pre-unit-eval.md`, Quiz 1 |
| **L2 Understand** | Contrast Flexbox (1D) vs CSS Grid (2D), semantic `<h1>` SEO impact, & `ctx.save()`/`ctx.restore()` around transforms | Slides, Lesson 10.1–10.2 |
| **L3 Apply** | Implement accessible labeled forms (`form-dom.html`), ARIA live regions, responsive `@media`, & Canvas 2D rotations | `0-student_files/11-html-css-dom/` |
| **L4 Analyze** | Audit broken HTML for missing `alt`, unlabeled `<input>`, heading skips (`<h1> -> <h4>`), & XSS via `innerHTML` | Quiz 2, Post-Unit Eval |
| **L5 Evaluate** | Select native CSS vs Tailwind/Bootstrap & native Canvas vs SVG/Charting libs given bundle budget & team skills (`15.11`) | Post-Unit Eval Q7–Q8 |
| **L6 Create** | Build an **Accessible Interactive Canvas Sketchpad & LocalStorage Palette Gallery** passing ARIA, keyboard & responsive checks | **Unit 10 Project** (`0-student_files/projects/unit-10-accessible-canvas-app/`) |
