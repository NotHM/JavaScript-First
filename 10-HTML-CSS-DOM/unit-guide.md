# Unit 10 Guide: UCD, Accessibility, Responsive CSS, 2D Canvas, DOM & Computer Vision

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 14–15 (Days 68–77 | 10 Class Periods × 50 Minutes incl. AI & Computer Vision Track)

## 1. Unit Overview
Unit 10 delivers comprehensive mastery of **AZ CTE Standard 15.0 (`15.1–15.11`)** alongside **West-MEC `AI101` Unit 2, `AI102` Unit 10, and `AI201` Units 3–4 (`AI Stds 3.0, 8.0, 9.0`)**. Students progress from **User-Centered Design (UCD)**, wireframes, **W3C Semantic HTML5**, **ADA Section 504/508 & WCAG Accessibility**, and **SEO (`15.1–15.3, 15.8–15.10`)** into **CSS Box Model / Flexbox / Grid / `@media`/`@print`**, **2D HTML5 Canvas Transforms** (`translate`/`rotate`/`scale`), GUI form validation, DOM events, **UI/CSS Library evaluation (`15.4–15.7, 15.11`)**, and **Computer Vision Pixel/Matrix Processing** (Canvas RGBA `ImageData` luminance, $3 \times 3$ **Box Blur & Sobel Edge Convolutions**, Binary Thresholding, **Bounding-Box `IoU`**, **AI Compute Hardware `CPU/GPU/TPU/NPU`**, and **CV Biometric/Surveillance Ethics**).
