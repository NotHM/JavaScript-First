# Lesson Plan 10.1: Accessible Forms, Responsive CSS & DOM Events

**Unit:** Unit 10 — HTML, CSS, Accessibility, SEO & DOM  
**Duration:** 5 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 2.0, Standard 3.0, Standard 19.0; AZ CTE Professional Skills 1.0, 3.0

## Learning Objectives
Students will be able to:
1. Build an accessible HTML form with semantic labels and validation.
2. Style a responsive layout using `box-sizing: border-box`, Flexbox, and `@media` queries.
3. Handle `submit` events and update the DOM dynamically in JavaScript.
