# Unit 2 Guide: Internet Protocols, Subnetting, Routing, Cloud, HTTP & Express SSR

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 10–11 (Days 46–53 | 8 Class Periods × 50 Minutes)

## 1. Unit Overview
Unit 2 delivers full mastery of **AZ CTE Standard 8.0 (Internet Protocols, Cloud Service Models, Server Roles, Performance & IoT)** alongside **Standard 11.3–11.7 (Building HTTP Request/Response Servers, Static Middleware & Modular SSR in Node.js)** and **IT Security Network Engineering (`West-MEC ITS 102 / Cisco CCNA 200-301` & `ADE Network Security 3.0, 6.0, 7.0, 8.1–8.5, 10.1–10.6`)**. Students analyze transport/application protocols (`HTTP`/`HTTPS`/`SSH`/`SFTP`/`IMAP`/`IPv4`/`IPv6`), evaluate `SaaS`/`PaaS`/`IaaS`/`FaaS`, engineer multi-route `node:http` servers with JSON/HTML `Content-Type` headers and `404`/`405` handling, refactor templates into modular ES-module SSR (`routes.mjs`, `components/`, `layout/`, `pages/`) compared cleanly against `Express.js`, and master binary/hex IP & MAC addressing, OSI 7-layer vs. TCP/IP 4-layer encapsulation, Star/Mesh/Spine-Leaf topologies, UTP vs. SMF/MMF fiber vs. `802.11 WPA3`/`802.15`/`5G CBRS`, **CIDR & VLSM subnetting**, RFC 1918 vs. IPv6, IANA port ranges, longest-prefix routing, STP failover, and the **7-Step Network Troubleshooting Methodology**.
