## Bloom's Objective Ladder
- **L1–L2:** State `package.json` ESM settings, Express static middleware syntax, and the 4 modular SSR layers.
- **L3 Apply:** Build composable `renderNavLinks` / `renderLayout` functions, MIME lookup, and `path.resolve()` containment in `expressLab.js`.
- **L4 Analyze:** Diagnose unescaped template literal XSS and unvalidated `path.join` directory traversal vulnerabilities.
- **L5 Evaluate:** Defend zero-dependency `node:http` vs. Express middleware based on cold starts, CVE surface, and feature velocity.

## Pacing & Teacher Answer Keys
- **Day 1 (50 min):** `pre-lesson-eval.md` (4m) → Slides & Refactor walkthrough (`slides/slides.md`, 18m) → Guided run of `code/expressVsNodeSsrDemo.mjs` & `code/expressStarterReference.mjs` (15m) → Part A + start `expressLab.js` (13m).
- **Day 2 (50 min):** Complete `expressLab.js` (22m) → Part C Security Hunt & Part D Architecture Debate (18m) → `post-lesson-eval.md` Exit Ticket (10m).
- **Pre 2.3 Key:** 1) `"type": "module"`; 2) Separates route data, reusable UI partials, shared HTML shell, and data-fetching pages for testability and reuse; 3) `express.static(...)`; 4) Enables **XSS (Cross-Site Scripting)** if `userInput` contains `<script>` tags.
- **Post 2.3 Key:** 1) `routes.mjs`, `components/`, `layout/template.mjs`, `pages/`; `layout/template.mjs` renders the shared HTML5 document shell (`<head>`, nav, `<main>`, `<footer>`); 2) Automatic MIME detection, `Content-Length`/ETags, and blocking `../` traversal outside the public root; 3) Replace `&`, `<`, `>`, `"`, `'` with `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#39;`; 4) **Path Traversal** exposing server secrets (`.env`); block with **HTTP `403 Forbidden`**; 5) (a) Lambda edge redirector → **bare `node:http`** (zero dependencies, fast cold start, tiny footprint); (b) 15-route club portal → **Express.js** (`express.static()`, `express.json()`, clean routing ergonomics).
- **Worksheet Part A & C Key:** Part A: `routes.mjs`=route metadata array; `components/nav.mjs`=pure nav HTML fragment; `layout/template.mjs`=shared HTML5 wrapper; `pages/catalog.mjs`=combines data + components + layout; `"type": "module"`=enables ESM `import`/`export`. Part C: Defect 1 = Reflected **XSS** via unescaped `req.query.name` (fix with `escapeHtml`); Defect 2 = **Path Traversal** via raw `path.join(PUBLIC_DIR, req.query.file)` allowing `../../` escapes (fix with `path.resolve` prefix check or `express.static`).
