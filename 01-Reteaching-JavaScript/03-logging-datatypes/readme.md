# Logging & Data Types

## Student Learning Objectives
By the end of this section, you should be able to:
1. Identify JavaScript's primitive types (`string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`) and non-primitive object types using `console` and `typeof`.
2. Explain the historical `typeof null === "object"` quirk and how to check for `null` reliably (`value === null`).
3. Demonstrate conditional logic (`if`/`else` and ternary operators) by writing JavaScript type-checking functions.
