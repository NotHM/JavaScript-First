# Lesson Plan 9.1: Debugging, TDD & Binary Search

**Unit:** Unit 9 — Debugging, TDD & Algorithms  
**Duration:** 4 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 4.0, Standard 18.0 (18.1–18.5); AZ CTE Professional Skills 3.0

## Learning Objectives
Students will be able to:
1. Set a breakpoint in VS Code and inspect variable state.
2. Write and run unit tests using `node:test` and `node:assert/strict`.
3. Implement `binarySearch(arr, target)` and `isPalindrome(str)` using TDD.
