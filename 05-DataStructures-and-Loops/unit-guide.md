# Unit 5 Guide: Iterative Structures, Arrays, Matrices & Data Structures

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 4–5 (Days 18–24 | 7 Class Periods × 50 Minutes)

---

## 1. Unit Overview
Unit 5 delivers comprehensive coverage of **AZ CTE Standard 7.0 (Iterative Structures)** and **AZ CTE Standard 6.0 (Data Structures & Collections)**. Students master loop mechanics (`while`, `for`, `for...of`, `.forEach()`, `break`/`continue`, nested loops, trace tables, and recursion) alongside core structures: 1D Arrays, Hash Maps (`Object`/`Map`), 2D Matrices, Trees, Graphs, `JSON`, and non-mutating transforms (`.map`, `.filter`, `.reduce`).

## 2. Arizona CTE Standards Alignment
| Standard | Official Indicators | Unit 5 Lessons |

| **Standard 7.0** — Utilize Iterative Structures | `7.1` `while`, `for`, `forEach`, recursion; `7.2` loop exit/`break`/`continue`; `7.3` nested loops; `7.4` tracing nested loop variables; `7.5` diagramming iteration | **Lesson 5.1:** [`01-Iteration-and-Loops/`](./01-Iteration-and-Loops/readme.md) |
| **Standard 6.0** — Utilize Basic Data Structures | `6.1` Arrays init/access/args; `6.2` Arrays vs. Hash Maps; `6.3` User-defined structures; `6.5` 2D arrays/matrices; `6.8` Trees & Graphs | **Lesson 5.2:** [`02-Arrays-Objects-Matrices/`](./02-Arrays-Objects-Matrices/readme.md) |
| **AZ CTE Prof. Skills** | `3.0` Thinking & Innovation | Execution trace tables & pipeline modeling |

## 3. Bloom's Taxonomy Progression Matrix (L1 → L6)
| Tier | Focus | Artifacts |
|---|---|---|
| **L1 Remember** | Identify loop keywords (`for`/`while`/`break`/`continue`), base case in recursion, and data structure terms (Array, Matrix, Map, Tree, Graph) | `pre-unit-eval.md`, Quiz 1 |
| **L2 Understand** | Hand-trace variables across nested loops (`i`, `j`) and contrast array index access vs. hash-map key lookup ($O(1)$) | Trace tables in Lesson 5.1 & 5.2 |
| **L3 Apply** | Implement nested matrix traversal, recursive `factorial`, and `.filter`/`.map`/`.reduce` chains | `0-student_files/06-data-structures/` |
| **L4 Analyze** | Debug infinite loops, off-by-one boundary defects, and tree/graph DFS vs. BFS path bugs | Quiz 2, Post-Unit Eval |
| **L5 Evaluate** | Select Array vs. `Map` vs. 2D Matrix vs. Tree/Graph for specific app workloads with Big-O justification | Post-Unit Eval Q9, Project Rubric |
| **L6 Create** | Engineer a **2D Gradebook Matrix & Prerequisite Course Graph Engine** with analytics CLI | **Unit 5 Project** (`0-student_files/projects/unit-05-matrix-gradebook/`) |
