# Lesson Plan 5.1: Loops, Recursion, JSON & Array Methods

**Unit:** Unit 5 — Control Flow, Loops & Data Structures  
**Duration:** 4 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 3.0 (3.4), Standard 4.0; AZ CTE Professional Skills 3.0

## Learning Objectives
Students will be able to:
1. Iterate over arrays using `for`, `for...of`, and `.forEach()`, and write a recursive countdown/factorial function.
2. Serialize and parse data with `JSON.stringify()` and `JSON.parse()`.
3. Transform datasets using `.map()`, `.filter()`, and `.reduce()`.
