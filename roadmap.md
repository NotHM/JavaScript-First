### 1. Program Architecture & Bloom's-Driven Instructional Model

**JavaScript First** is engineered simultaneously as an **open-source engineering textbook** (featuring long-form `@HansOnCoding` Medium-style chapter readings and standalone `setup-guide.md` setup standards in every unit) and a **West-MEC Node-First 2-Year (900-Hour / 4-Semester / 6.0 HS Credits) CTE curriculum** spanning **20 Instructional Units**, **46 Standard Lessons**, **49 Reveal.js slide decks**, **60 Kahoot quizzes (`1,466` items: `40` Quiz 1/2 formative decks + `20` × 50-Question Unit Mastery Exams)**, **220+ trackable Student & Teacher SMART Goals**, **automated Red → Green TDD lab & capstone suites (`58` registered `node:test` suites / `220` automated checks via `npm run grade`)**, **pre/post evaluations at both lesson and unit granularity**, and **20 hands-on L5–L6 projects** culminating in a **Full-Stack Local Multimodal AI & 3D CAD/Printing Capstone** (while preserving a structured **18-Week / 90-Day Core Fast-Track** across Units `01–16`). In addition to **ADE Software and App Design (`11.0202.00`)**, the 10 expanded sub-lessons (`1.5`, `2.4`, `5.3`, `7.2`, `9.3`, `10.3`, `11.2`, `12.2`, `19.3`, `20.3`) embed core technical competencies from **West-MEC Artificial Intelligence (`11.0102.00`)**, **West-MEC Drone Technology (`49.0199.00`)**, and **West-MEC IT Security / ADE Network Security (`11.1999.00`)**.

Rather than trapping beginners inside a fragile browser console on Day 1, students master JavaScript first inside **Node.js**—building rigorous engineering discipline in module resolution (`.mjs`/`.cjs`), Linux/POSIX admin & hardware safety, computer mathematics & LiPo/geodesic flight physics, immutability, data cleaning & feature engineering, ML fairness & graph algorithms, TDD (`node:test`), `node:http`, CIDR/VLSM subnetting & Express SSR, async drone telemetry fail-safes, databases, security (`TLS`/`AES-256-GCM`/Zero Trust/Firewalls/SIEM), **Deno capability sandboxes & WebAssembly**, **Bun SQLite & MongoDB REST APIs**, **Phaser 3 / `jsgamelauncher` & Part 107 Flight Sims**, and **Local Multimodal AI, NLP, ReAct Agents & Model Cards**.

### Every Lesson Delivers 8 Synchronized Components
1. **Diagnostic Pre-Lesson Evaluation (`pre-lesson-eval.md`)** — 3–5 min baseline readiness & misconception probe (`L1–L4`).
2. **Book Reading (`readme.md`)** — Self-paced technical text mapped explicitly to AZ CTE indicators (paired with each unit's long-form `@HansOnCoding` **Chapter `readme.md`** and **`setup-guide.md`**).
3. **Reveal.js Slideshow (`slides/*.md`)** — `vscode-reveal` classroom presentation with interactive *"Predict Before Running"* checks.
4. **Instructor Reference Code (`code/`)** — Executable Node/Deno/Bun/Browser demos & zero-daemon offline `node:test` suites.
5. **Blank Student Lab (`0-student_files/`)** — Unsolved `TODO` starter workspace paired with active Red → Green `node:test` suites graded automatically via `npm run grade` ([TDD Guide](./0-student_files/README.md)).
6. **Student Worksheet (`student-lesson.md`)** — Solution-free Parts A–D escalating **L1 Remember → L6 Create**, plus trackable **Lesson SMART Objectives checkboxes**.
7. **Teacher Lesson Plan (`lesson-plan.md`)** — 50-minute pacing script, Bloom's ladder, SMART Goals alignment, differentiation & full answer keys.
8. **Summative Post-Lesson Evaluation (`post-lesson-eval.md`)** — Paired exit ticket proving same-day student growth.

### Every Unit (`01`–`20`) Delivers 6 Unit-Level Assessment & Onboarding Layers
- **Medium Chapter & Setup Standard (`readme.md` + `setup-guide.md`)** — Deep concept narrative in `@HansOnCoding`'s Medium voice plus exact toolchain versions, verification commands, and troubleshooting matrices.
- **Unit Guide (`unit-guide.md`)** — Day-by-day pacing, AZ CTE mapping, Bloom's L1–L6 matrix, and **$\ge 5$ Student + $\ge 5$ Teacher Trackable SMART Goals (`- [ ]`)** detailing Specific, Measurable, Achievable, Relevant, and Time-bound criteria (`6+` each in cross-program expanded units).
- **Automated TDD Gradebook (`npm run grade` / `tools/grade.mjs`)** — Runs all registered lab and project `node:test` suites per unit (`100` pts/unit) to guide Red → Green mastery before coding sign-off.
- **Pre/Post Unit Evaluations (`evaluations/`)** — Day 1 Baseline (`pre-unit-eval.md`), Final Day Summative (`post-unit-eval.md`), and Teacher Key (`eval-answer-key.md`) using **Hake's Normalized Learning Gain** $g = \frac{\text{Post\%} - \text{Pre\%}}{100 - \text{Pre\%}}$ (Target: $g \ge 0.55$).
- **Formative Quizzes + 50-Question Comprehension Mastery Exam (`quizzes/`)** — `quiz-1-concepts` (L1–L2), `quiz-2-application` (L3–L5), AND a comprehensive **50-Question Unit Mastery Exam** (`unit-test-50.md` Student Exam, `unit-test-50-answer-key.md` Teacher Key, `unit-test-50-kahoot.csv` 50-row Kahoot CSV = **`1,000`** unit exam items across `20` units).
- **Authentic Engineering Project (`projects/`)** — Multi-day `unit-project.md` build, test-driven starter scaffold in `0-student_files/projects/unit-XX-*/`, and 4-tier `project-rubric.md`.

## 3. 18-Week (90-Day) Single-Semester Core Fast-Track View

Schools teaching **JavaScript First** as a **single-semester (90-day × 50-min)** accelerated course cover **Units `01–16`** sequentially across **4 Quarters** while treating **Units `17–20`** as Honors / Year 2 / After-School Extension Modules:

- **Q1 (Days 1–24 | Wks 1–5):** `Unit 01` (incl. `1.4–1.5`) → `Unit 12` (incl. `12.2`) → `Unit 04` → `Unit 05` (incl. `5.3`)
- **Q2 (Days 25–45 | Wks 6–9):** `Unit 06` → `Unit 13` → `Unit 14` → `Unit 09` (incl. `9.3`)
- **Q3 (Days 46–67 | Wks 10–13):** `Unit 02` (incl. `2.3–2.4`) → `Unit 03` → `Unit 07` (incl. `7.2`) → `Unit 15`
- **Q4 (Days 68–90 | Wks 14–18):** `Unit 10` (incl. `10.3`) → `Unit 08` → `Unit 11` (incl. `11.2`) → `Unit 16`
- **Year 2 / Honors Extension (Units `17–20`):** `Unit 17` (Deno/WASM) → `Unit 18` (Bun SQLite + MongoDB REST) → `Unit 19` (Phaser, `jsgamelauncher` & Part 107 Sim `19.3`) → `Unit 20` (Local AI, NLP/Agentic Governance `20.3` & 3D CAD/Printing)
