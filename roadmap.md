## 1. Program Architecture & Bloom's-Driven Instructional Model

**JavaScript First** is engineered simultaneously as an **open-source engineering textbook** and a **West-MEC Node-First 2-Year (900-Hour / 4-Semester / 6.0 HS Credits) CTE curriculum** spanning **20 Instructional Units**, **36 Standard Lessons**, **39 Reveal.js slide decks**, **40 Kahoot quizzes**, **200+ trackable Student & Teacher SMART Goals**, **pre/post evaluations at both lesson and unit granularity**, and **20 hands-on L5–L6 projects** culminating in a **Full-Stack Local Multimodal AI & 3D CAD/Printing Capstone** (while preserving a structured **18-Week / 90-Day Core Fast-Track** across Units `01–16`).

Rather than trapping beginners inside a fragile browser console on Day 1, students master JavaScript first inside **Node.js**—building rigorous engineering discipline in module resolution (`.mjs`/`.cjs`), computer mathematics, immutability, algorithms & graph theory, TDD (`node:test`), `node:http` & Express SSR, concurrency, databases, security (`TLS`/`AES-256-GCM`), **Deno capability sandboxes & WebAssembly**, **Bun SQLite & MongoDB REST APIs**, **Phaser 3 / `jsgamelauncher` handheld games**, and **Local Multimodal AI**.

### Every Lesson Delivers 8 Synchronized Components
1. **Diagnostic Pre-Lesson Evaluation (`pre-lesson-eval.md`)** — 3–5 min baseline readiness & misconception probe (`L1–L4`).
2. **Book Reading (`readme.md`)** — Self-paced technical text mapped explicitly to AZ CTE indicators.
3. **Reveal.js Slideshow (`slides/*.md`)** — `vscode-reveal` classroom presentation with interactive *"Predict Before Running"* checks.
4. **Instructor Reference Code (`code/`)** — Executable Node/Deno/Bun/Browser demos & zero-daemon offline `node:test` suites.
5. **Blank Student Lab (`0-student_files/`)** — Unsolved `TODO` starter workspace aligned to L3–L4 application and analysis.
6. **Student Worksheet (`student-lesson.md`)** — Solution-free Parts A–D escalating **L1 Remember → L6 Create**, plus trackable **Lesson SMART Objectives checkboxes**.
7. **Teacher Lesson Plan (`lesson-plan.md`)** — 50-minute pacing script, Bloom's ladder, SMART Goals alignment, differentiation & full answer keys.
8. **Summative Post-Lesson Evaluation (`post-lesson-eval.md`)** — Paired exit ticket proving same-day student growth.

### Every Unit (`01`–`20`) Delivers 4 Unit-Level Assessment Layers + SMART Tracking
- **Unit Guide (`unit-guide.md`)** — Day-by-day pacing, AZ CTE mapping, Bloom's L1–L6 matrix, and **$\ge 5$ Student + $\ge 5$ Teacher Trackable SMART Goals (`- [ ]`)** detailing Specific, Measurable, Achievable, Relevant, and Time-bound criteria.
- **Pre/Post Unit Evaluations (`evaluations/`)** — Day 1 Baseline (`pre-unit-eval.md`), Final Day Summative (`post-unit-eval.md`), and Teacher Key (`eval-answer-key.md`) using **Hake's Normalized Learning Gain** $g = \frac{\text{Post\%} - \text{Pre\%}}{100 - \text{Pre\%}}$ (Target: $g \ge 0.55$).
- **Two Kahoot Formative Quizzes (`quizzes/`)** — `quiz-1-concepts` (L1–L2 Remember/Understand) and `quiz-2-application` (L3–L5 Apply/Analyze/Evaluate), each with a teacher rationale key (`.md`) and validated 7-column Kahoot import CSV (`-kahoot.csv`).
- **Authentic Engineering Project (`projects/`)** — Multi-day `unit-project.md` build, starter scaffold in `0-student_files/projects/unit-XX-*/`, and 4-tier `project-rubric.md`.

## 3. 18-Week (90-Day) Single-Semester Core Fast-Track View

Schools teaching **JavaScript First** as a **single-semester (90-day × 50-min)** accelerated course cover **Units `01–16`** sequentially across **4 Quarters** while treating **Units `17–20`** as Honors / Year 2 / After-School Extension Modules:

- **Q1 (Days 1–24 | Wks 1–5):** `Unit 01` (incl. `1.4`) → `Unit 12` → `Unit 04` → `Unit 05`
- **Q2 (Days 25–45 | Wks 6–9):** `Unit 06` → `Unit 13` → `Unit 14` → `Unit 09`
- **Q3 (Days 46–67 | Wks 10–13):** `Unit 02` (incl. `2.3`) → `Unit 03` → `Unit 07` → `Unit 15`
- **Q4 (Days 68–90 | Wks 14–18):** `Unit 10` → `Unit 08` → `Unit 11` → `Unit 16`
- **Year 2 / Honors Extension (Units `17–20`):** `Unit 17` (Deno/WASM) → `Unit 18` (Bun SQLite + MongoDB REST) → `Unit 19` (Phaser + `jsgamelauncher`) → `Unit 20` (Local AI + 3D CAD/Printing)

*(You can export dedicated Year 1 and Year 2 volumes directly via `npm run build:year1` and `npm run build:year2`!)*

## 6. Publishing & Classroom Tooling (`tools/publish.mjs`)

Generate synchronized print books (Pandoc + Chromium PDF) and all **39 Reveal.js slide presentations** into `dist/`:

```bash
npm run build:student   # -> dist/JavaScript-First-Student-Book.pdf  (Solution-free textbook, evals & labs: Units 01–20)
npm run build:teacher   # -> dist/JavaScript-First-Teachers-Manual.pdf (Guides, SMART goals, plans, keys & rubrics: Units 01–20)
npm run build:slides    # -> dist/slides/*.html (All 39 Reveal.js decks; append ?print-pdf for slide PDFs)
npm run build:year1     # -> Year 1 (West-MEC CO101 + CO102) Student Book & Teacher's Manual PDFs
npm run build:year2     # -> Year 2 (West-MEC CO201 + CO202) Student Book & Teacher's Manual PDFs
npm run build:all       # -> Builds complete Student Book, Teacher's Manual, and all 39 Reveal.js slide decks
```
