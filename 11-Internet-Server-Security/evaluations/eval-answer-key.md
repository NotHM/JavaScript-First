# Unit 11 Evaluation Answer Key (Teacher Only)

## Pre-Unit Key (11 pts)
1. **Confidentiality, Integrity, Availability** | 2. **B** (`Principle of Least Privilege`) | 3. AES encrypts/decrypts symmetrically with a secret key; `scrypt` is slow one-way salted hashing for password verification | 4. `XSS` (Cross-Site Scripting) | 5. Treats input parameters strictly as literal SQL data values rather than executable SQL syntax | 6. `..` (`../`, `..\\`) | 7. **CVEs** catalog known security flaws with severity scores (`npm audit`); **SIEM** centralizes security logs to detect anomalies/intrusions quickly | 8. Standard `===` short-circuits on the first mismatch byte letting attackers time secret character guesses; `timingSafeEqual` executes constant-time comparisons | 9. **At Rest**, **In Motion**, **In Use**; a **Faraday bag** blocks RF/cellular/Wi-Fi signals to prevent remote device wipes or wireless tracking | 10. Stateless **Packet-Filtering** inspects each packet independently without flow state, whereas **Stateful** firewalls track `ESTABLISHED` connections automatically; **biometrics** cannot be revoked/rotated once leaked, triggering severe **BIPA / GDPR** legal liability | 11. **RPO** = max tolerable data loss age; **RTO** = max tolerable downtime duration; student records = **`FERPA`**, healthcare PHI = **`HIPAA`**, payment cards = **`PCI-DSS`**.

## Post-Unit Key (16 pts)
1. Phishing/AI=`MFA + Out-of-Band Verification`; Known flaw=`CVE tracking + Patch/npm audit`; Brute-force spikes=`SIEM alerting + Rate limiting`.
2. **Digital Signatures** cryptographically verify publisher identity & integrity (`unmodified binary`); **Sandboxes/VMs** isolate untrusted execution away from host files/OS.
3. `const salt = crypto.randomBytes(16).toString('hex'); const derived = crypto.scryptSync(password, salt, 32).toString('hex');`
4. Escapes `& -> &amp;`, `< -> &lt;`, `> -> &gt;`, `" -> &quot;`, `' -> &#39;`.
5. Joining unvalidated strings escapes `/app/uploads` reading host `.env` secrets! Fix: `const base = path.resolve('/app/uploads'); const resolved = path.resolve(base, req.query.name); if (!resolved.startsWith(base + path.sep)) throw new Error('Blocked');`
6. Violates **Confidentiality** (leaks host stack details & permits cross-origin reads) and **Least Privilege**.
7. **At Rest** (`BitLocker`/LUKS) protects stolen storage vs. **In Motion** (`TLS 1.3`/VPN) protects network links; **`VLAN`** separates L2 broadcast domains while **`DMZ`** creates a screened public buffer subnet isolating internal DBs; central biometrics are non-revocable once breached, triggering **BIPA / GDPR Art. 9** statutory privacy liability.
8. `IP_BAD` is **permitted** because ACLs run **first-match wins** (Rule 1 matches before Rule 2; fix by putting specific `DENY` *above* general `ALLOW`); **IDS** passively alerts while inline **IPS** actively blocks packets; **NGFW L7** inspects HTTP/TLS payloads (e.g., SQLi/C2 inside port `443`).
9. **2 pts:** (1) Revoke & rotate compromised token immediately (Least Privilege scope); (2) Check SIEM access logs for abuse window; (3) Disable SSH passwords in favor of Ed25519 keys + MFA on admin logins; (4) Enforce pre-commit secret scanning & `.gitignore`.
10. **2 pts:** Identical unsalted MD5 digests allow instant precomputed **Rainbow Table** lookup AND billions/sec **GPU brute force**; unique random salts foil rainbow tables while memory-hard slow **`scrypt`/`Argon2`** slows brute force exponentially!
11. **2 pts:** Enforces `startsWith(base + path.sep)` check, runs `escapeHtml(searchTerm)`, and emits `{ sql: 'SELECT * FROM files WHERE name = $1', params: [searchTerm] }`.
12. **2 pts:** Risk = `5 × 4 × 5 = 100` (**CRITICAL**). STRIDE threats = **Spoofing** (`CREDENTIAL_COMPROMISE` + `IMPOSSIBLE_TRAVEL_SSO`) & **Information Disclosure** (`AI_EXFILTRATION_ANOMALY` 1.2 MB spike) (+ **Repudiation** mitigated by SIEM logs). DRP = **`Hot Site`** (`RPO <= 5m`, `RTO <= 15m`). Applicable laws: **`GDPR`** (EU citizens), **`HIPAA`** (US hospitals/PHI), **`PCI-DSS`** (card payments), plus **`SOX` / `AUP`** governance.
