# Unit 11 Guide: Cybersecurity, OWASP, Cryptography, Zero Trust, SIEM & STRIDE

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Weeks 17–18 (Days 81–87 | 7 Class Periods × 50 Minutes)

## 1. Unit Overview
Unit 11 delivers comprehensive mastery of **AZ CTE Standard 1.0 (`1.1–1.7`)** alongside **Hardened HTTP Server Engineering** and **IT Security Enterprise Defense (`West-MEC ITS 201–202` — `CompTIA Security+`, `TestOut Security Pro`, & `ADE Network Security 1.0, 4.5–4.6, 5.1–5.10, 9.1–9.10, 10.7–10.8, 11.1–11.6`)**. In Lesson 11.1, students analyze social engineering & AI spoofing, apply the **CIA Triad** and **Least Privilege / MFA**, contrast reversible **Encryption (`AES-256-GCM`)** with salted **Password Hashing (`scrypt`)**, remediate **OWASP Top 10** injection/XSS/path-traversal flaws, and harden a Node HTTP API. In Lesson 11.2, students engineer Zero Trust controls spanning the 3 Data States (At Rest/In Motion/In Use), Risk Matrix (`Asset × Likelihood × Impact`), **STRIDE** threat modeling, physical security (`BitLocker`/Faraday), AAA/SSO (`SAML`/`OIDC`) & biometric privacy liability (`BIPA`/`GDPR`), `VLAN`/`DMZ` segmentation, Packet-Filtering vs. Stateful vs. Application/NGFW firewalls + `IDS/IPS`, **SIEM correlation + AI anomaly detection**, Disaster Recovery (`RPO`/`RTO` Hot/Warm/Cold sites), and regulatory compliance (`GDPR, HIPAA, PCI-DSS, SOX, FERPA, FCC, DRM, EFF, AUP`).
