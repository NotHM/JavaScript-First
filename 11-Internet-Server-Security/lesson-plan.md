# Lesson Plan 11.1: DNS, Modules & Web Security

**Unit:** Unit 11 — Internet, Server Architecture & Web Security  
**Duration:** 4 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 1.0, Standard 2.0 (2.3–2.4), Standard 16.0; AZ CTE Professional Skills 1.0, 8.0

## Learning Objectives
Students will be able to:
1. Trace how DNS resolves a domain name to a hosted server IP.
2. Explain HTTPS, CORS, and XSS prevention.
3. Build a Node.js server with security headers (`X-Content-Type-Options`) and HTML escaping.
