# Unit 14 Guide: Program Analysis, SDLC & Software Design (`Std 10.0`)

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Week 8 (Days 35–39 | 5 Class Periods × 50 Minutes)  
**Setup & CLI Guide:** [`setup-guide.md`](./setup-guide.md) · **Automated Lab Grader:** `npm run grade -- --unit 14`

## 1. Unit Overview
Students step back from writing syntax alone to master **Software Analysis, Architecture & Engineering Design (Standard `10.0`)**—bridging user requirements, compliance, language/database selection, problem decomposition, UML/flowcharts, troubleshooting, and production telemetry.

## 2. Bloom's Taxonomy Progression Matrix (L1 → L6)
| Tier | Focus | Evidence |
|---|---|---|
| **L1 Remember** | State all 7 SDLC phases, RAD/RUP models, and compliance acronyms (HIPAA, PCI DSS, GLBA) | `pre-unit-eval.md`, Quiz 1 |
| **L2 Understand** | Contrast JS, Python, Java, C# and explain SQL vs. NoSQL architectural trade-offs (`10.3, 10.6`) | `slides/slides.md`, Part A |
| **L3 Apply** | Write Given/When/Then user stories, decompose workflows into sub-functions, and emit telemetry JSON (`10.2, 10.7, 10.10`) | `0-student_files/14-program-design/` |
| **L4 Analyze** | Trace production incident root causes systematically (`10.9`) and detect unencrypted compliance gaps (`10.5`) | Quiz 2, Post-Unit Eval |
| **L5 Evaluate** | Select & justify SQL vs. NoSQL, JS vs. Python, and RAD vs. RUP for real client requirements | Post-Unit Eval Q8 |
| **L6 Create** | Architect a **Clinic Telehealth Booking Spec, Flowchart, Decomposed Modules & Telemetry Plan** | **Unit 14 Project** (`0-student_files/projects/unit-14-system-spec/`) |
