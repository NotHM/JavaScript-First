# Unit 19: Game Development with Phaser.js & `jsgamelauncher`

Unit 19 bridges web game programming and dedicated retro handheld deployment using **HTML5 2D Canvas**, the **W3C Gamepad API**, **Web Audio API**, **Phaser 3**, and [**`monteslu/jsgamelauncher`**](https://github.com/monteslu/jsgamelauncher) (grounded in [`developing-games.md`](https://github.com/monteslu/jsgamelauncher/blob/main/docs/developing-games.md), [`simple-jsgame-starter`](https://github.com/monteslu/simple-jsgame-starter), and [`jsgames/simple-phaser`](https://github.com/monteslu/jsgames/tree/main/simple-phaser)).
