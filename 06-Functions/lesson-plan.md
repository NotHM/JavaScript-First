# Lesson Plan 6.1: Functions, Closures & Currying

**Unit:** Unit 6 — Functions & Functional Programming  
**Duration:** 4 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 3.0, Standard 4.0, Standard 18.0; AZ CTE Professional Skills 3.0

## Learning Objectives
Students will be able to:
1. Write function declarations, expressions, arrow functions, and IIFEs.
2. Build stateful utilities using closures without global variables.
3. Implement pure functions, higher-order functions, and curried functions.
