# Lesson Plan 7.1: Promises, `async`/`await` & Event-Driven Concurrency

**Unit:** Unit 7 — Asynchronous JavaScript & Concurrency  
**Duration:** 3 Class Periods (50 minutes each)  
**AZ CTE Standards:** Software & App Design 11.0202.00 — Standard 16.0 (16.3), Standard 18.0 (18.1, 18.7); AZ CTE Professional Skills 3.0

## Learning Objectives
Students will be able to:
1. Trace Event Loop execution order (`console.log`, `Promise.resolve().then()`, `setTimeout`).
2. Create and await Promises using `async`/`await` and `try`/`catch`.
3. Emit and listen to custom events with Node's `EventEmitter`.
