# Unit 7 Guide: Asynchronous Concurrency, Error Handling & Drone Telemetry (`Std 18.0` + `DT101–DT102`)

**Course:** JavaScript First — Software & App Design (AZ CTE CIP **11.0202.00**)  
**Semester Schedule:** Week 12–13 (Days 57–64 | 8 Class Periods × 50 Minutes)

## 1. Unit Overview
Unit 7 delivers complete mastery of **AZ CTE Standard 18.0 (Runtime Concurrency & Exception Handling Engineering)** combined with **West-MEC Drone Technology `DT101–DT102` (`11.0–16.0, 24.0–26.0`)**. In **Lesson 7.1** (at unit root), students master Node's **Event Loop, Promises, `Promise.all` vs. `Promise.allSettled`, `EventEmitter`, `AsyncQueue`/`AsyncTree`, and Streams**, classifying error origins & severity levels (`18.1–18.4`), guarding `null`/`NaN` returns (`18.5`), designing custom `Error` subclasses (`18.6`), and coordinating resilient `try`/`catch`/`finally` flows (`18.7`). In **Lesson 7.2**, students apply those exact async patterns to **sUAS RF Telemetry Links (`2.4 GHz` C2 / `5.8 GHz` FPV / `900 MHz` telemetry, `RSSI`/`SNR`/`LQ`)**, **16-byte MAVLink/CRSF-style `Uint8Array`/`DataView` + CRC-16 packet decoding**, **PID control with anti-windup**, **Complementary IMU sensor fusion**, **`AbortController` + `finally` Heartbeat Watchdog Fail-Safe State Machines (`HOVER`/`RTH`/`LAND`)**, and **`PIC`/`VO` CRM callouts**.
