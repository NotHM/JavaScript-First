# Using the Fetch API (Browser & Node.js)

The **Fetch API** provides a modern, Promise-based interface (`fetch()`) for making HTTP requests.

## Files in This Section
- [`index.html`](./index.html) — Browser-based `fetch()` example.
- [`node-fetch.js`](./node-fetch.js) — Server-side `fetch()` example in Node.js.

## Running the Node.js Example

```bash
npm install
node node-fetch.js
```

> **Note:** Node.js 18+ also includes a built-in global `fetch()` API, so `node-fetch` is only needed for older Node.js versions.
