# Unit 16 & Semester Capstone Rubric (Teacher Only)

| Criterion | Bloom's | Exemplary (25 pts) | Proficient (20 pts) | Needs Support (10 pts) |
|---|---|---|---|---|
| **Architecture & Security (`1.0, 17.0, 18.0`)** | L4 Analyze | Hardened XSS/path/salted auth, modular SOLID code, graceful error handling & `finally` guards. | Minor validation gap or monolithic main file. | Plaintext passwords, XSS, or unhandled crashes. |
| **Persistence & Accessible UI (`15.0, 16.0`)** | L5 Evaluate | Atomic CRUD storage + WCAG `4.5:1` responsive UI + keyboard ARIA support. | Missing responsive media query or partial a11y labels. | Data wiped on restart or inaccessible UI. |
| **Testing & Git Professionalism (`12.0, 14.0`)** | L5 Evaluate | Passing `node --test` boundary assertions (`npm test`) & clean commit history. | Happy-path tests only. | Zero automated tests or broken syntax. |
| **SaaS Business Case & Pitch (`19.0`)** | L6 Create | Accurate break-even, `LTV:CAC >= 3:1` math, store channel strategy, & disciplined MVP scope. | Rough cost guess lacking churn/LTV math. | Unviable pricing or missing business plan. |
