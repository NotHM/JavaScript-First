5. Enforce Sprint Backlog freeze, strict **WIP limits** on Kanban boards, and defer unassigned extras into `Phase 2 Backlog`.

7. **2 pts:** Avionics -> **Waterfall** (safety verification & immutable compliance sign-off gates); EdTech -> **Agile/Scrum** (fast classroom usability feedback loops each sprint).
8. **2 pts:** Users abandon before experiencing core value (`Time-to-Value UX friction`, not billing)! Instrument onboarding funnel events (`Step 1 -> Step 2`), interview dropoffs (`19.7`), and test simplified 1-click sample project onboarding via A/B experiment!
